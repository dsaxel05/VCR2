Stated vs. computed
If the deck says 134% NRR and the cohort maths says 118%, that gap is the finding. Eighteen checks run on every assessment.

Stage-calibrated bars
Seed companies are not graded against Series B thresholds, and retention metrics are suppressed below the customer count where they carry signal.
🔁
Reproducible output
Every run carries a rubric version and an input hash. The same inputs produce the same score today and in nine months at the IC.
🔎
Provenance on every field
Extracted values keep the line of source text they came from, so an associate can trace any number back without reopening the data room.
📋
Output is a question list
Not a verdict. A ranked set of what to verify in the data room, what to negotiate, and what to make a closing condition.

Radar is a workflow tool. It does not give investment advice and its score is not a recommendation to buy or sell a security.
